# FinOne block library - Stage 1 (tokenized 1:1 rebuild)

The engineer's ACF blocks (finone.finalytics.ai/blocks) rebuilt as brand-agnostic components. Same DOM, same class
hierarchy, same responsive behaviour; every brand colour, font, radius and container width reads from `tokens.css`.
No theme picker yet (Stage 2).

## Open it

```bash
python3 -m http.server 8010        # from this folder (or preview "finone-blocks")
```

- `kitchen-sink.html` - all 58 blocks + header + footer, in the engineer's order (static, built by `node tools/build_kitchen_sink.mjs`)
- `verify.html` - structural diff harness: renders every block client-side and compares it to the engineer's markup. Shows `VERIFY 60/60`.

## Deviations from the engineer's build (deliberate)

1. **Share Certificate Calculator is not a 1:1 copy.** On the engineer's `/blocks` page `#fin-cd-calculator` is an empty mount (a vendor script fills it elsewhere and is not loaded there), so there is no markup or CSS to match. Built to the brief: Initial Deposit, APY %, Term Length pills, live compound result. Verification ignores the mount's children. Needs your call on whether the real widget exists somewhere to copy.
2. **Rate tables are static rows.** The engineer's theme JS replaces `.rates-table` with data fetched from WordPress. `vendor/main.min.js` has one patch: that hydration is opt-in (`.rates[data-remote]`). Rows came from the live DOM.
3. **Assets are localised** (`assets/uploads/`) instead of loading from the live site.
4. `wp-json/acf/v3/options/options` is a stub so the speedbump (external-link warning) works locally.
5. `blocks.css` keeps `--swiper-theme-color: #007aff` (Swiper default) as the engineer did; their nav arrows are tinted through `--color-secondary`.
6. Header logo is the Finalytics lockup, as on the engineer's page; footer logo is Granite's. Both are props.
7. The engineer's markup contains stray `</p>` tags the browser turns into empty `<p></p>` (product cards). Reproduced so DOM and spacing match.

## Stage 2 - Theme and Page Customizer

Open `customizer.html` (`kitchen-sink.html` is unchanged and is the baseline). Code: `js/customizer/` (presets, theme, stack, render, main), `customizer.css`.

- **Brand tab:** presets (Granite, Harbor, Evergreen, Summit), import/export `theme.json`, copy `:root` CSS; 7 colour controls bound to tokens (Primary also drives `--color-primary`, which Swiper now reads); Google Font loader for heading/body/rate fonts; button shape and card radius; org name, routing, NMLS, logo, hero/promo images.
- **Page Builder tab:** default homepage or blank; add from the 58-block library; hide, move up/down or drag to reorder; per-block spacing, background tone and variant props. Click a block in the preview to select it.
- **Toolbar:** Desktop 1440 / Tablet 768 / Mobile 390 (iframe, so media queries fire); Hide controls.
- **Lifecycle:** structural changes rebuild the preview iframe, so Swiper, accordions and menus initialise once on fresh markup with no duplicate listeners. Token/font changes update CSS variables live without reload.
- State persists in localStorage (uploaded images do not).

### Stage 3 polish
- **Copy and data editing:** selecting a block shows its text fields in the inspector (eyebrow, headline, body, button labels, rate-strip figures, rate-table rates, card/step/quote text, calculator defaults). Edits live in the block props.
- **theme.json v2** now includes the whole page (`page[]`: type, props, hidden), so export/import saves a full client mockup. v1 files (theme only) still import.
- **Templates:** Default homepage, Product Detail, Lending / Promo Landing, News & Community, Blank canvas.
- Verified in the browser: templates, drag reorder, logo/hero upload, custom Google Font (Outfit), file import. No console errors.

### Full-bleed layer (`fullbleed.css`)
Loaded by the customizer only (kitchen-sink / verify stay the 1:1 baseline). Heroes (marquee, large, medium, small), Promo Full and Banner Full span the viewport edge to edge while content stays in the centred `--container-max-width` (alias of `--container-max`, 1440px). Photography is `width/height: 100%`, `object-fit: cover`, `object-position: center center`, with `min-height` clamps (`clamp(...)` by viewport, capped at 640px for splits, 760px marquee, 820px banner). Preview widths now include 1920 and 2560. Promo Split/Offset/Product keep the engineer's `center top` crop.

## Layout 02 (variants.css)

- Hero marquee `fade: true` - gradient-fade: cover/centre photo dissolving into `--color-tertiary` (#4b56a8 in Granite) plus a left scrim.
- Rate strip `appearance: 'frosted'` - brand-dark strip, translucent cards, white text.
- Promo `brandDark: true` (+ `badges: [{store:'apple'|'google'}]`) and `edge: true` (media flush to the viewport edge, 50/50, copy inside the container).
- Page Builder template "Layout 02": hero fade, frosted rate strip, brand-dark app promo, edge-to-edge promo, 3 image cards. Header and footer are site chrome.
- Note: `--color-primary` is the accent; the brand-dark blue is `--color-tertiary`, so the variants use that token.
